# ResourceFlow Website

Static marketing site built from the supplied ResourceFlow logo and website concept/PDF.

## Publish free
1. Create a GitHub repository (for example `resourceflow-website`).
2. Upload `index.html`, `style.css`, and the `assets` folder.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Save. GitHub will provide the live site URL.

Replace placeholder links/email addresses when ready.
